# Morse Jogger

I apologize in advance to anyone that tries to read this code.

I wanted to play [Morse Runner Community Edition
](https://github.com/w7sst/MorseRunner) on my iPhone, so I told GPT-6 to copy
it. I hacked at it for a while via both prompts and text editors. Then I told
Fable 5.2 to review and clean it up. Opus 5.5 had a hand in the fun too.

This is the result. I've tested it and tuned the parts I use, but I'm sure
there are still bugs. I'll fix them as they're reported.

Much credit is due to: [Alex VE3NEA](https://github.com/VE3NEA/MorseRunner) for
the original idea, and to Mike W7SST for the community fork. Thanks to all
involved for using an open source license so I can do this :)

## Features

In theory, it has all the features of MRCE. Some of them even work!

It's playable in the default state for the SST, I haven't played the rest
extensively.
